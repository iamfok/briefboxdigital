# Briefbox Digital website (briefboxdigital.com)

Static site generated by build.js from content/*.json. No dependencies.

## Upload to GitHub (keep the folders)
Upload everything: admin/, assets/, content/, build.js, package.json, vercel.json. Vercel rebuilds automatically.

## Deploy on Vercel
Add New Project > import the repo > Framework Preset: Other > Deploy. Then Settings > Domains > add briefboxdigital.com and set it as Primary, so briefboxdigital.vercel.app redirects to it.

## Admin panel: /admin
Sign in with owner/repo, branch main and a GitHub fine-grained token (only this repo, Contents: Read and write).
Edit, then press Save and publish. Roles come from GitHub permissions (Admin = Super Admin, Write = Editor, Read = Viewer).

## Content files
site.json (menus, footer, home and page texts, tracking, booking) · services.json (service pages and pricing) · pages.json · posts.json · faqs.json
Prices appear only on /pricing. Test locally: node build.js (output in dist/).

## After launch (SEO)
Submit https://briefboxdigital.com/sitemap.xml in Google Search Console and Bing Webmaster Tools. Add your real address, phone and social links in the admin.
